What the dates mean

Mainstream support

At least the first five years. Microsoft sends security updates and other fixes, and still accepts requests for non-security fixes.

Extended support

Security updates only, at no extra cost. When it ends, so do the security fixes. For Windows Server and SQL Server this is the date that matters.

Paid Extended Security Updates

For some versions Microsoft sells up to three more years of security fixes, paid for yearly. Some versions get them at no extra charge when they run in Microsoft Azure.

One date: .NET and Windows 11

These have a single end date per version. .NET LTS releases get three years and STS releases two; Windows 11 is supported version by version.

Common questions

What happens when Windows Server reaches end of support?
It keeps running, but Microsoft stops sending security updates for it. Any security hole found after that date stays open, and Microsoft no longer fixes other bugs either. The only way to keep getting Microsoft's security fixes is paid Extended Security Updates, and only for versions where Microsoft offers them.
Can I still run an unsupported server?
Yes. Nothing switches off on the end date. But you are then running it without security fixes. If it holds personal data, the PDPA's Security Principle expects you to take practical steps to protect that data, and cyber insurers and larger customers may ask whether your software is still supported. If you cannot move yet, take the server off the internet, restrict who can reach it and keep tested offline backups while you plan the move.
What is ESU?
Extended Security Updates are a paid Microsoft programme that continues security fixes for some products after extended support ends, usually for up to three years, paid for yearly. They include no new features and no other fixes. For Windows Server 2012 and 2012 R2 they ended on 13 October 2026. For SQL Server 2014 they run until 12 July 2027, and for SQL Server 2016 until 17 July 2029. Some versions get them at no extra charge when they run in Microsoft Azure.
Is .NET Framework 4.8 end of life?
No. .NET Framework 4.8 and 4.8.1 have no end date of their own: they are part of Windows and are supported for as long as the Windows version they run on. On Windows Server 2022 that is until 14 October 2031; on Windows Server 2016, until 12 January 2027. Microsoft does give 4.6.2 its own end date, 12 January 2027, and versions 4.5.2 to 4.6.1 ended on 26 April 2022.
Is .NET 8 still supported?
Until 10 November 2026, the same day as .NET 9. .NET 10, released on 11 November 2025, is the current Long Term Support release and is supported until 14 November 2028.
