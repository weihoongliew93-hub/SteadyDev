What an audit catches

Things a cost dashboard won't tell you

Your cloud provider gives you resize suggestions for free. They don't know what those changes will break, or what has already been changed in your account.

A saving that was breaking production

A server had been resized months earlier, halving its memory. The bill went down, then the machine started killing its own database under load. The real cause was a cache set to 78% of memory. Fixing that cost nothing, and the smaller machine was fine.

A cost plan built on wrong facts

Services listed for migration had already been migrated. A charge blamed on the main API came from a batch server. None of it was visible without reading the audit logs.

Deploys weeks from failing

Old app versions had piled up to 200 of a hard 210 limit. Nobody had noticed, because nothing fails until the day you can't ship a fix.
