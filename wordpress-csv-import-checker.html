      SteadyPost is lenient about a lot, so this checker doesn't complain about these:

      • Column order, and the case, spaces and punctuation in header names.
      • Blank rows, blank lines above the header, and spaces around values.
      • Semicolon-separated files, as Excel saves them in countries that use a decimal comma.
      • Files saved in Windows-1252 rather than UTF-8, with or without a byte order mark.
      • Rows with fewer cells than the header: the missing ones count as blank.
      • Dates typed into Excel that arrive as day numbers.

      Common questions

      Which columns does SteadyPost need?
      Only a title. Every other column is optional, and columns it doesn't recognise are ignored unless you map them on the Import screen. Header names are matched without regard to case, spaces or punctuation, so "Publish Date", "publish_date" and "PUBLISH-DATE" are the same column.
      What date format should I use?
      Use YYYY-MM-DD HH:MM, for example 2026-11-01 09:00. SteadyPost reads it in your site's timezone. Dates with slashes are read month first, so 03/11/2026 becomes 11 March, and 13/11/2026 can't be read at all. Dates with dashes or dots, such as 03-11-2026, are read day first.
      How do I separate categories and tags?
      With commas or vertical bars, such as News, Events or News | Events. Semicolons are not separators. Categories and tags that don't exist yet are created during the import.
      Why do accents or Chinese characters come out wrong?
      SteadyPost reads a CSV as UTF-8. If the file isn't valid UTF-8, it assumes Windows-1252, the encoding Excel uses for plain CSV on Windows. That keeps Western European accents but garbles Chinese, Tamil and other scripts. In Excel, save as CSV UTF-8 (Comma delimited) instead.
      Will importing the same file twice create duplicate posts?
      No. Each row is matched to the post it created, by a Ref column, then the slug, then the title, and that post is updated. The same applies inside one file: two rows with the same slug or title become one post, and the later row's values win.
