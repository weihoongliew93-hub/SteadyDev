Semakan tamat sokongan Microsoft

Pilih versi Windows Server, SQL Server, .NET atau Windows anda dan lihat bila Microsoft berhenti menghantar pembaikan keselamatan untuknya, berapa lama masa yang tinggal, dan sama ada Extended Security Updates berbayar boleh memberi anda masa tambahan.

Tidak pasti? Pada Windows, jalankan winver. Dalam SQL Server, jalankan SELECT @@VERSION. Untuk .NET, jalankan dotnet --list-runtimes.

Anda juga boleh memilih mana-mana versi daripada jadual di bawah. “Hari ini” ialah tarikh pada peranti anda.

Microsoft masih membaiki pepijat dan lubang keselamatan dalam versi ini. Teruskan memasang kemas kininya dan anda dilindungi.

Microsoft kini menghantar pembaikan keselamatan sahaja: tiada ciri baharu dan tiada pembaikan pepijat lain. Ia selamat selagi anda terus menampal, tetapi mula merancang perpindahan sebelum tarikh di atas.

Microsoft masih menghantar pembaikan keselamatan untuk versi ini, selagi anda memasangnya.

Kurang daripada setahun lagi. Menguji aplikasi pada versi yang lebih baharu dan memindahkannya biasanya mengambil masa berbulan-bulan, bukan berhari-hari. Mulakan sekarang.

Microsoft tidak lagi membaiki lubang keselamatan yang ditemui di dalamnya. Ia terus berjalan, sebab itulah risikonya mudah terlepas pandang. Jika sistem itu menyimpan data pelanggan, juruaudit, syarikat insurans atau pelanggan anda mungkin bertanya tentangnya.

Microsoft masih menjual Extended Security Updates untuknya sehingga : pembaikan keselamatan sahaja, dibayar setahun demi setahun. Cara untuk mendapatkan masa untuk berpindah, bukan tempat untuk kekal.

Extended Security Updates berbayar juga telah tamat, jadi tiada lagi cara untuk mendapatkan pembaikan keselamatan Microsoft untuknya.

Halaman kitaran hayat Microsoft tidak menyenaraikan Extended Security Updates berbayar untuk versi ini.

.NET Framework 4.5.2 dan yang lebih baharu ialah sebahagian daripada Windows. Ia menerima pembaikan keselamatan selagi versi Windows tempat ia dipasang disokong. Semak versi Windows itu sebaliknya: pada Windows Server 2016 ialah sehingga 12 Januari 2027, pada Windows Server 2022 sehingga 14 Oktober 2031. Versi 4.x yang lebih baharu dipasang menggantikan versi sebelumnya, dan Microsoft menjangkakan aplikasi yang dibina untuk 4.x terdahulu terus berjalan padanya.

Tarikh itu terpakai pada Windows 10 versi 1809, Windows Server 2019 dan yang lebih baharu, di mana 3.5 SP1 ialah produk tersendiri. Pada Windows yang lebih lama, ia sebahagian daripada sistem pengendalian dan tamat apabila versi Windows itu tamat.

Halaman .NET Framework Microsoft memberikan 4.6.2 tarikh tamatnya sendiri. 4.8 dan 4.8.1 dipasang menggantikannya, dan Microsoft menjangkakan aplikasi yang dibina untuk 4.6.2 terus berjalan padanya tanpa perlu dibina semula.

.NET hanya disokong pada tampalan terkininya, jadi pastikan runtime sentiasa dikemas kini. Keluaran Long Term Support (LTS) mendapat tiga tahun, keluaran Standard Term Support (STS) dua tahun.

Ini tarikh bagi edisi Home dan Pro. Berpindah ke versi Windows 11 yang lebih baharu sebelum tarikh itu untuk terus disokong. Edisi Enterprise dan Education mempunyai tarikh sendiri.

Organisasi boleh membeli Extended Security Updates Windows 10 setahun demi setahun, sehingga tiga tahun; Microsoft menyebut harga US$61 bagi setiap peranti untuk tahun pertama, berganda setiap tahun. Versi 22H2 diperlukan.

Tarikh daripada Microsoft: halaman kitaran hayat bagi setiap produk (dipautkan di bawah setiap jadual) dan dasar sokongan .NET dan .NET Core (kali terakhir dikemas kini 13 Oktober 2026). Microsoft memberikannya dalam Waktu Pasifik AS, jadi di Malaysia hari terakhir berakhir pada petang berikutnya. Disemak pada 23 Oktober 2026. Microsoft boleh menukar tarikh ini, jadi sahkan tarikh anda di halamannya sebelum merancang berdasarkannya. Bukan nasihat.

Maksud tarikh-tarikh ini

Sokongan arus perdana

Sekurang-kurangnya lima tahun pertama. Microsoft menghantar kemas kini keselamatan dan pembaikan lain, dan masih menerima permintaan untuk pembaikan bukan keselamatan.

Sokongan lanjutan

Kemas kini keselamatan sahaja, tanpa kos tambahan. Apabila ia tamat, pembaikan keselamatan turut tamat. Bagi Windows Server dan SQL Server, inilah tarikh yang penting.

Extended Security Updates berbayar

Bagi sesetengah versi, Microsoft menjual sehingga tiga tahun lagi pembaikan keselamatan, dibayar setiap tahun. Sesetengah versi mendapatnya tanpa caj tambahan apabila berjalan dalam Microsoft Azure.

Satu tarikh: .NET dan Windows 11

Ini mempunyai satu tarikh tamat bagi setiap versi. Keluaran .NET LTS mendapat tiga tahun dan keluaran STS dua tahun; Windows 11 disokong mengikut versi.

Soalan lazim

Apa yang berlaku apabila Windows Server tamat sokongan?
Ia terus berjalan, tetapi Microsoft berhenti menghantar kemas kini keselamatan untuknya. Sebarang lubang keselamatan yang ditemui selepas tarikh itu kekal terbuka, dan Microsoft tidak lagi membaiki pepijat lain. Satu-satunya cara untuk terus mendapat pembaikan keselamatan Microsoft ialah Extended Security Updates berbayar, dan hanya bagi versi yang ditawarkan oleh Microsoft.
Bolehkah saya masih menjalankan pelayan yang tidak disokong?
Boleh. Tiada apa-apa yang dimatikan pada tarikh tamat. Tetapi anda kemudiannya menjalankannya tanpa pembaikan keselamatan. Jika ia menyimpan data peribadi, Prinsip Keselamatan PDPA menjangkakan anda mengambil langkah praktikal untuk melindungi data itu, dan syarikat insurans siber serta pelanggan yang lebih besar mungkin bertanya sama ada perisian anda masih disokong. Jika anda belum boleh berpindah, putuskan pelayan daripada internet, hadkan siapa yang boleh mengaksesnya dan simpan sandaran luar talian yang telah diuji sementara anda merancang perpindahan.
Apakah ESU?
Extended Security Updates ialah program berbayar Microsoft yang meneruskan pembaikan keselamatan bagi sesetengah produk selepas sokongan lanjutan tamat, biasanya sehingga tiga tahun, dibayar setiap tahun. Ia tidak termasuk ciri baharu dan pembaikan lain. Bagi Windows Server 2012 dan 2012 R2, ia tamat pada 13 Oktober 2026. Bagi SQL Server 2014, ia berjalan sehingga 12 Julai 2027, dan bagi SQL Server 2016 sehingga 17 Julai 2029. Sesetengah versi mendapatnya tanpa caj tambahan apabila berjalan dalam Microsoft Azure.
Adakah .NET Framework 4.8 sudah tamat hayat?
Tidak. .NET Framework 4.8 dan 4.8.1 tiada tarikh tamat sendiri: ia sebahagian daripada Windows dan disokong selagi versi Windows tempat ia berjalan disokong. Pada Windows Server 2022 ialah sehingga 14 Oktober 2031; pada Windows Server 2016, sehingga 12 Januari 2027. Microsoft memberikan 4.6.2 tarikh tamatnya sendiri, 12 Januari 2027, dan versi 4.5.2 hingga 4.6.1 tamat pada 26 April 2022.
Adakah .NET 8 masih disokong?
Sehingga 10 November 2026, hari yang sama dengan .NET 9. .NET 10, yang dikeluarkan pada 11 November 2025, ialah keluaran Long Term Support semasa dan disokong sehingga 14 November 2028.
