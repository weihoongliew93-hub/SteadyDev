如何运作

从电子表格到已发布的文章，无需猜测

每一步都在您的 WordPress 后台完成。以下都是插件的真实截图。

01 · 模板

从模板开始，而不是一张白纸

下载空白或示例电子表格，每篇文章填一行，再上传回来。列会自动对应。

  • Excel 模板附带 Status 下拉列表和一张说明工作表
  • 可加入您自己的自定义字段、ACF 字段和分类法的列
  • 只有 Title 是必填的，其他全部可选
  • Excel、Numbers、LibreOffice 和 Google Sheets 的文件都可以使用

02 · 预览

每一行变成文章之前，都能先看到

预览会显示每一行和每一列，并附有勾选框。您可以全部导入、只导入几行，或只导入 "ready" 列批准的行。

  • 在任何操作发生之前，勾选、取消勾选和筛选行
  • 行筛选列——勾选框、状态，或“尚未导入”
  • 无法导入的行会被标出，并注明原因

03 · 试运行

先知道会发生什么，再动手。

试运行会检查每一个已勾选的行，准确告诉您正式导入会做什么——而且不保存任何内容。

  • 哪些文章会新建，哪些会更新
  • 尚不存在的分类和标签
  • 找不到或无法读取的作者、图片和日期

04 · 历史记录与撤销

改变主意了？整次导入一键撤销。

每次导入都会连同完整日志保存下来。撤销会把该次导入新建的文章移到回收站，并把它更新过的文章完全恢复原样。

  • 每篇文章被修改之前，都会先保存一个修订版本
  • 确认之前，您能看到撤销将会做什么
  • 移到回收站的文章仍可从回收站恢复

05 · 批量编辑

在 Excel 里编辑数百篇现有文章

导出文章——任何文章类型，可按状态、分类或日期筛选——修改需要的单元格，再上传文件。每一行都会更新它来自的那篇文章，即使那篇文章并非由 SteadyPost 创建。

- Meta Title: 秋季菜单 | Harbour Lane Café
+ Meta Title: 2026 秋季菜单——南瓜面包与香料拿铁

一次坐下来修好 200 个 SEO 标题，然后只需上传一次。

常见问题

大家常问的问题

SteadyPost 真的免费吗？
是的。本页的每项功能都在免费插件里，行数、文章和网站数量都不受限制，并以 GPL 开源。没有付费版本。如果您更希望有人帮您完成大型迁移，那是另外的工程服务。
可以上传哪些文件格式？
.xlsx 和 .csv。Excel、Apple Numbers、LibreOffice 和 Google Sheets 都能保存成其中一种。Excel 文件读取的是第一张工作表。Excel 以 Windows 编码保存、或以分号作分隔符的 CSV 文件，都会自动识别。
同一个文件导入两次，会产生重复的文章吗？
不会。每一行都会对应到它新建的那篇文章——通过 Ref 列、slug 或标题——并在原处更新。如果您更想跳过已经导入过的行，可以在 Settings 里关闭这个功能。
可以撤销导入吗？
可以，在 SteadyPost → History。该次导入新建的文章会移到回收站，您仍可从那里恢复。被它更新过的文章，会取回导入前一刻的标题、内容和摘要，来自 SteadyPost 当时保存的修订版本。分类、自定义字段和 SEO 字段不会回滚。
可以批量编辑已有的文章吗？
可以。在 SteadyPost → Export 导出，编辑电子表格后再上传。Post ID 列会告诉 SteadyPost 每一行属于哪篇文章，所以适用于任何文章，不只是 SteadyPost 新建的。
文章正文怎么写？
写在 Content 列里，可以是纯文本（空一行即开始新段落）、Markdown（例如 ## Heading 和 **bold**）或 HTML。SteadyPost 会逐行识别是哪一种。也可以在 Google Doc 列放一个 Google Doc 链接，该文档就会成为正文。
图片怎么处理？
在 Featured Image 列放图片 URL，图片就会下载到您的媒体库。也可以在 Import 页面上传图片 zip 包，再按文件名引用——hero.jpg 作为特色图片，或在内容中写 ![alt](photo.png)。zip 包里没有的文件名，会到您的媒体库中查找。无论多少行用到同一张图片，它都只会添加一次。
需要 Google 账户吗？
不需要。SteadyPost 完全靠您上传的文件运作。Google Sheets 和 Google Docs 是可选功能，适合本来就在那里规划内容的团队。
能配合我的 SEO 插件吗？
Meta 标题、描述和关键词会写入 Yoast SEO、Rank Math 或 SEOPress（以启用中的为准），也支持 Mikado/Qode 主题的 SEO 字段，或您指定的任何 meta 键。All in One SEO 把数据存放在自己的数据表中，因此不支持。
有什么系统要求？
WordPress 6.0 或更新版本，以及 PHP 7.4 或更新版本。Excel 文件需要 PHP 的 Zip 扩展，几乎所有主机都有；没有它，CSV 仍然可用。
在 WordPress.org 上有吗？
正在提交到 WordPress.org 插件目录。上架之前，请从本页下载——是同一个插件。上架后，更新会自动出现在您的后台。
