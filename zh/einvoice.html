现实情况

电子发票里最容易出问题的环节，都替您处理好了。

难懂的拒绝代码

LHDN 的拒绝信息只说明违反了哪条规则，并不告诉您怎么改。常见原因在发送前就会被发现；若 LHDN 仍然拒绝，系统会显示原因和出错的字段。修改后一键重新提交，免费。

证书悄悄过期

证书一过期，提交就会停止。只需上传一次；在影响您之前的 60 天和 7 天都会提醒您。

每月 7 号的慌乱

三月的发票必须在 4 月 7 日晚上 11:59（马来西亚时间）前提交。系统会提前几天提醒您，截止时间过后不会再发送任何发票。

超过 RM 10k 却缺少买家 TIN

LHDN 不允许高价值销售使用通用 TIN。这个问题在提交前就会被发现，所以发票不会被退回。第四阶段（Phase 4）企业可以开启 LHDN 的宽松措施，该规则将暂停至 2027 年 12 月 31 日。

验证

发票送达 LHDN 之前的三道检查。

每张发票在提交前都要通过三层检查。问题会连同字段名称显示在您的仪表板上；LHDN 永远看不到有问题的发票。

  1. 1
    结构有发票号码吗？项目有效吗？数量为正数吗？日期能解析吗？如果不符合，会立即拒收。
  2. 2
    LHDN 完整性卖方的 TIN、MSIC 和地址齐全吗？超过 RM 10,000 的销售有买家 TIN 吗？有分类代码吗？如果没有，发票会被暂扣，等您修正。
  3. 3
    产品主档税种、税率和分类代码会从您的产品目录自动填入。

产品主档

税务代码只需在产品上设置一次。

分类代码、税种和税率都存放在每个产品上。使用该产品的每一行发票都会正确填写，不必每张发票重新输入，也不会在 LHDN 要求 H87 的地方出现“PCS”。

合并电子发票

门市销售，7 号前完成提交。

门市销售会先等待，看买家是否要求开立自己的电子发票。月底仍未认领的销售，会作为一张合并电子发票提交给 LHDN，可在每月 1 号自动提交或一键提交，并在 LHDN 的 7 天期限之前提醒您。退款会对应到正确的电子发票，超过 RM 10k 的销售会被标记，需单独开立电子发票。

运作方式

从连接到合规。

  1. Connect

    生成 API 密钥并把发票推送到 REST 接口，上传电子表格，或由我们为您系统的导出格式编写映射适配器。

  2. Validate

    每张发票都要通过三层检查。问题会连同说明出现在您的仪表板上；没有问题的发票会自动排队。

  3. Submit

    发票以您的 TIN 提交到 MyInvois。LHDN 截止时间过后不会再发送。

  4. Sync & notify

    每 5 分钟检查一次状态，更新您的仪表板，并通过 webhook 通知您的系统。

系统对接

与您现有的系统配合使用。

三种接入方式，现已全部可用：REST API、电子表格上传，以及我们为您系统的导出文件编写的映射适配器。目前还没有现成的品牌连接器；早期合作伙伴会在上线辅导期间获得专属编写的连接器。

  • POS 系统。StoreHub 或任何定制 POS，通过 API 或为其导出文件编写的适配器接入。
  • ERP 与会计软件。SQL Account、AutoCount、SAP 或任何能导出 Excel 或 CSV 的 ERP，先提供模板并试运行。
  • 电子商务。WooCommerce、Shopify 或定制结账流程，由您商店的 webhook 发送每一笔订单。
  • 其他任何系统。只要能发出 HTTP POST，就能接入。使用 API 密钥验证，无需繁琐的 OAuth。

配套说明

  1. Premium 合理使用：Premium 没有发票数量上限。若账户在一个月内超过 20,000 次提交，我们会联系您讨论定制配套；每月持续超过 40,000 张则需要改用定制配套。
  2. 服务抵扣：如发生未达正常运行目标的情况，最多相当于一个月订阅费的服务抵扣会计入下一个账单周期。服务抵扣是唯一的补偿方式；对于因服务中断而错过 LHDN 截止日期或造成的间接损失，我们不承担责任。
  3. 优先支持：我们会为您指定一位支持联系人。在支持团队达到满员之前，非紧急问题的回复时间可能超过 4 小时的目标；我们会在开通时清楚说明预计的回复时间。
  4. 电邮提醒：证书到期提醒和系统通知会通过已设置的 SMTP 发送。开通时，我们会协助您连接电邮服务（SendGrid、AWS SES 或公司自己的 SMTP）。演示账户的提醒只显示在仪表板内。

超额计费：超过每月额度后，每张额外发票按配套收费（RM 0.09–0.30），绝不会阻止您报税。在用到额度的 80% 和 95% 时会提醒您。超额费用在每月 1 号结算，并加到下一次付款中：月付配套加到下一次月费，年付配套则加到续费时。重新提交免费：一张发票无论修改并重新提交多少次，都只计算一次。

常见问题。

平台如何连接 LHDN？
通过 LHDN 官方的 MyInvois API，以您自己的 TIN 提交。目前您使用自己的 MyInvois 凭证连接，开通时我们会一步步引导您完成。由 SteadyDevs 作为您的中介代为提交（您只需在 MyInvois 授权一次）即将推出。
我需要自己的数字证书吗？
目前需要：您使用自己的 MyInvois 凭证连接，需要一张来自 LHDN 认可供应商的证书。您只需在“设置”中上传一次，到期前 60 天会收到提醒。待 SteadyDevs 可以作为您的中介代为提交（即将推出）后，您就不再需要证书。
如果 LHDN 拒绝了发票怎么办？
被拒绝的发票会出现在“LHDN 拒绝”下，附上 LHDN 的原因及出问题的字段，例如“Enter valid e-mail address - BUYER”。修正资料后一键重新提交即可。重新提交免费：一张发票无论修改并重新提交多少次，都只占用一次月度额度。大多数常见原因，例如缺少买家 TIN 或行业代码（MSIC）无效，在发票发送之前就会被发现。
一个账户可以管理多家公司吗？
定制配套可以：每家公司在同一个登录下拥有自己的 TIN、LHDN 凭证、数字证书和提交记录。其他配套中，每家公司各自是一个账户。如果您经营多个实体，请联系我们。
每一笔散客销售都要提交给 LHDN 吗？
不用逐笔提交。散客销售可以不填买家 TIN 记录下来；想要自己电子发票的买家仍然可以申请。到了月底，所有未被认领的销售会合并成一张电子发票提交给 LHDN，LHDN 要求在 7 天内完成。可以开启在每月 1 号自动提交，也可以先预览再自行提交；若到了 3 号还未提交，系统会提醒您。散客销售的退款会针对其所在的合并电子发票处理。单笔超过 RM 10,000 的销售需要单独开立电子发票并附上买家资料，除非您的企业适用第四阶段宽松措施。
我的企业必须开电子发票吗？什么时候开始？
年营业额达到 RM300 万或以上的，必须开。营业额不超过 RM500 万的企业（第四阶段）目前处于过渡宽松期，至 2027 年 12 月 31 日为止：所有销售都可以每月开立合并电子发票，2028 年 1 月 1 日起全面实施规则。如果符合，请在 设置 > 企业资料 中开启“Phase 4 relaxation”，平台对日期在 2027 年 12 月 31 日或之前的发票将不再执行 RM 10,000 买家 TIN 规则。营业额低于 RM300 万可获豁免，但若您的企业股东、控股公司或关联公司营业额达 RM300 万或以上则除外。获豁免的企业仍可自愿加入，大客户要求提供电子发票时常常如此。来源：LHDN 实施时间表 及 我们 2026 年 10 月的总结（英文）。或用我们的免费自查工具确认您的日期和准备程度 →
Premium 真的没有上限吗？
是的，Premium 没有发票数量上限，也没有超额收费。但须合理使用：若账户在一个月内超过 20,000 次提交，我们会联系您讨论定制配套；每月持续超过 40,000 张则需要改用定制配套。

您可以随时下载全部资料，任何配套都可以，停止付费后也可以：发票、明细、买家、产品、设置和日志，格式为 JSON 及 CSV。若关闭账户，按照 PDPA 的规定，经过 7 天冷静期后，我们保存的所有资料都会被永久删除，完成后会发电邮通知您。已验证的电子发票仍可在 LHDN 的 MyInvois 上查阅。请保留好导出的资料：所得税法规定商业记录须保存七年。
Webhook 和 POS 连接器包括在配套内吗？
它们是附加功能，用不到的企业就不必付费：Webhook 每月 RM 19、POS 与 ERP 连接器每月 RM 29、买家认领门户每月 RM 19。通过 REST API 或 CSV 上传提交发票，所有配套都包括。
我的 POS 系统比较旧或是定制的，也能连接吗？
几乎一定可以。适配器系统本来就是为旧系统和定制系统设计的。只要您的 POS 能导出每日发票文件（CSV、JSON、XML）或发出 HTTP POST，就能连接。若是 .NET 系统，SteadyDevs 还可以与您现有的代码做紧密对接。
30 天试用是什么？试用结束后会怎样？
所有付费配套（Starter 至 Premium）都从 30 天免费试用开始，无需信用卡，所有功能都可使用。30 天后会请您添加付款方式；若不添加，账户会转为免费配套（每月 10 张发票）。不会删除任何发票。
我的 LHDN Client Secret 和证书存放安全吗？
安全。所有 LHDN 凭证在写入数据库前都以 AES-256-GCM 加密，主密钥另外存放。只有在提交时才会在内存中解密，绝不会出现在 API 回应中；仪表板也会隐藏密钥。
