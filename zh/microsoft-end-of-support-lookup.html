这些日期的含义

主流支持

至少最初五年。Microsoft 提供安全更新和其他修复，并仍接受非安全修复的请求。

扩展支持

仅限安全更新，不额外收费。扩展支持结束时，安全修复也随之结束。对 Windows Server 和 SQL Server 来说，这才是关键日期。

付费 Extended Security Updates

对于部分版本，Microsoft 会额外销售最多三年的安全修复，按年付费。部分版本在 Microsoft Azure 上运行时可免费获得。

单一日期：.NET 和 Windows 11

这些产品每个版本只有一个结束日期。.NET LTS 版本支持三年，STS 版本支持两年；Windows 11 按版本提供支持。

常见问题

Windows Server 支持终止后会怎样？
它会继续运行，但 Microsoft 不再为它提供安全更新。该日期之后发现的任何安全漏洞都不会被修补，Microsoft 也不再修复其他错误。唯一能继续获得 Microsoft 安全修复的办法是付费的 Extended Security Updates，而且只限 Microsoft 提供 ESU 的版本。
我还能继续运行不受支持的服务器吗？
可以。到了结束日期，什么都不会被关掉。但此后您就是在没有安全修复的情况下运行它。如果它存有个人资料，PDPA 的安全原则要求您采取切实措施保护这些资料，网络保险公司和较大的客户也可能会问您的软件是否仍受支持。如果暂时无法迁移，请让服务器断开互联网、限制可访问的人员，并在规划迁移期间保留经过测试的离线备份。
ESU 是什么？
Extended Security Updates 是 Microsoft 的付费计划，在扩展支持结束后继续为部分产品提供安全修复，通常最多三年，按年付费。不包含新功能和其他修复。Windows Server 2012 和 2012 R2 的 ESU 已于 2026 年 10 月 13 日结束。SQL Server 2014 的 ESU 到 2027 年 7 月 12 日，SQL Server 2016 到 2029 年 7 月 17 日。部分版本在 Microsoft Azure 上运行时可免费获得。
.NET Framework 4.8 已经停止支持了吗？
没有。.NET Framework 4.8 和 4.8.1 没有自己的结束日期：它们是 Windows 的一部分，只要所运行的 Windows 版本受支持，就会受支持。在 Windows Server 2022 上是到 2031 年 10 月 14 日；在 Windows Server 2016 上是到 2027 年 1 月 12 日。Microsoft 为 4.6.2 给出了单独的结束日期，即 2027 年 1 月 12 日，而 4.5.2 至 4.6.1 版本已于 2022 年 4 月 26 日结束。
.NET 8 还受支持吗？
到 2026 年 11 月 10 日为止，与 .NET 9 同一天结束。.NET 10 于 2025 年 11 月 11 日发布，是当前的长期支持版本，支持到 2028 年 11 月 14 日。
