功能一览

场馆接受预约所需的一切

顾客在线预约，提醒自动发出，而每笔预约都需您批准，一切尽在掌握。

实时多步骤预约

顾客选择日期和时间、资源和人数，然后确认。空档实时更新，两个人不可能抢到同一个时段。

管理员审批流程

每笔预约进来时都是待处理状态。您可以在后台批准、拒绝或取消；在您同意之前，不会有任何预约被确认。

防止重复预约

对于已确认的资源、日期和时间，插件会拒绝再次批准，同一个时段绝不会被预约两次。

自动预约提醒

在每笔已确认预约开始前的设定时数，系统会发出提醒电邮，让顾客准时出现，减少爽约。

在线付款 Class Portal

会员通过 HitPay（银行卡、PayNow 等）购买预付点数配套，点数自动发放。也支持银行转账等手动付款方式，由您确认。

前台员工角色 Class Portal

您的前台人员无需完整的管理员账户，就能确认付款、为课程点名和管理会员。

可编辑的电邮模板

您一批准或拒绝，顾客就会收到电邮。可通过实时预览调整措辞、颜色和标志，也可以关闭任何一封电邮。

高峰与非高峰定价

为每项资源设定高峰日子和费率；插件会在结账时自动套用，而不只是显示在标签上。

使用率与营收报表

每可用小时营收、星期 × 小时繁忙度网格、各资源表现、高峰与非高峰对比，以及提前预约时间中位数，并可导出 CSV。

Class Portal Pro 附加功能

经营定期课程，而不只是单次时段。会员登录、购买预付点数，并按每周课表预约，支持分级定价和候补名单。

WhatsApp 询问

可选的“Enquire via WhatsApp”按钮，会把完整的预约资料预先填入发给您商业号码的消息中。

短代码与 Elementor

用 [steadybook] 或内置的 Elementor 小工具，把表单放在任何位置。资源、价格和可预约期间都可配置。

颜色全面自定

一次设定强调色、按钮、文字、边框，以及可预约和已预约时段的颜色，整个预约流程就会配合您的品牌，深色或浅色背景皆可。

贴合页面的布局

调整宽度、间距、圆角，以及步骤和时段的排列方式，让表单自然融入您的页面。

适配任何主题

样式有独立作用域，绝不会与主题的 CSS 冲突，表单也会沿用您网站的字体排版。看起来像是网站原生的一部分，而不是后来硬加上去的。

常见问题

常见问题

SteadyDevs Venue Booking 适合哪些行业？
任何按时段预约的生意：运动球场和模拟器打击位、工作室和护理室、餐厅桌位、器材或装备租赁、美发座椅、会议室等等。资源、价格和营业时间都由您决定。
顾客可以在线付款吗？
课程可以。Class Portal 会员通过 HitPay 支付网关在线购买预付点数配套（银行卡、PayNow，以及您的 HitPay 账户支持的其他方式），付款后点数自动发放。同时也支持银行转账或柜台付款等手动方式，由您确认后才发放点数。至于单次按小时预约，目前由您在插件以外自行收款（在场馆现场、转账或开发票）。预约时收取订金的功能已列入开发路线图。
是否包含定期课程，而不只是单次时段？
是的。本页面的每个配套都包含 Class Portal：这是与按小时预约表单并行的第二种预约模式，会员登录后购买预付点数配套，并按每周课表预约。它还提供可选的分级定价（级别）、已满课程的候补名单、可打印的点名册，以及“Class Portal Staff”角色，让前台无需完整的管理员权限也能操作。欢迎试用上方的在线演示。（WordPress.org 上另有一个不含 Class Portal 的免费插件；本页面出售的是包含 Class Portal 的 Pro 版。）
有免费试用吗？
有：Starter 配套可免费试用 14 天，无需信用卡。您会获得解锁全部功能的完整插件，可以在考虑期间设置真实的资源并接受真实的预约。14 天结束时如果您什么都不做，试用就会自动停止，绝不会向您收费。Professional 和 Agency 不提供试用，但您可以先从 Starter 开始，满意后再升级。
购买后我实际会收到什么？
结账后您会立即获得可下载的插件 ZIP 文件和许可证密钥，两者都会显示在确认页面上，并发电邮给您。您把 ZIP 文件上传到 WordPress，再用密钥激活即可。
许可证涵盖什么？
插件的全部功能，以及订阅有效期间的更新和支持，可用于您配套允许的网站数量（1、5 或 25 个）。更新会在您的 WordPress 后台内自动安装。
我需要哪个配套？
所有配套解锁的都是同一个插件，唯一的区别是可以启用的网站数量。Starter（$299/年）适用于一个企业网站。Professional（$699/年）适用于 5 个网站，每个 $140。Agency（$1,499/年）适用于 25 个客户网站，每个 $60。需要超过 25 个？请联系我们，我们会按您的网站数量定制配套。您可以随时升级，只需支付差价。
测试和开发网站会占用许可证吗？
不会。测试、开发和本地安装（例如 staging.yoursite.com 或 yoursite.local）不计入网站数量限制，只有正式上线的网站才计算。
可以按月付款吗？
所有配套均按年收费。如果您想在承诺前先试用，可以开始 14 天免费试用：无需信用卡，全部功能解锁，如果觉得不适合，也无需办理任何取消手续。
有什么系统要求？
WordPress 5.0+ 和 PHP 7.2+。为了让审批电邮可靠送达，我们建议安装一个简单的 SMTP 插件（例如 WP Mail SMTP），这对任何需要发送邮件的 WordPress 网站来说都是标准做法。
缺少您场馆需要的功能？
告诉我们：在下方提交功能需求，我们通常在一个工作日内回复。开发路线图由真实场馆的需求推动，付费客户的需求会优先处理。如果您使用的是免费版，也可以到 WordPress.org 支持论坛提问。
如果我不续订会怎样？
您现有的预约和数据会保留在 WordPress 中。您只是在续订之前不再收到新的更新和支持。
